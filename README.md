# 하루기록 — 일일 업무일지

회사 업무일지 양식에 맞춰 하루의 업무를 작성하고 PDF로 저장하거나 공유하는 정적 웹 앱입니다.

## 실행

- 내 컴퓨터에서: `index.html`을 웹 브라우저로 엽니다.
- GitHub Pages: <https://poreQw.github.io/task/>

`main` 브랜치에 변경 사항을 올리면 `.github/workflows/pages.yml`이 사이트를 배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**가 **GitHub Actions**로 설정되어 있어야 합니다. 첫 배포가 완료된 뒤 위 주소에서 앱을 열 수 있습니다.

## 기능

- 이름, 날짜와 ① 지시받은 업무, ② 완료한 업무, ③ 해결하지 못한 문제, ④ 오늘 배운 내용, ⑤ 내일 할 일을 기록합니다.
- 자유 메모를 업무 항목별로 분류하고, 입력 문장을 업무일지 표현으로 다듬습니다.
- 날짜별 업무일지를 이 브라우저의 로컬 저장소에 보관하고 다시 열거나 삭제할 수 있습니다.
- 완성한 업무일지를 복사하거나 텍스트 파일로 저장하고, 기기의 공유 메뉴로 전달할 수 있습니다.
- 브라우저의 글꼴로 한국어·중국어가 보이도록 A4 PDF를 생성해 인쇄 창 없이 다운로드합니다.
- 반응형 화면과 A4 인쇄용 업무일지 서식을 제공합니다.

## 저장 및 공유 안내

- 업무일지 내용은 서버나 GitHub로 전송되지 않습니다. 작성한 브라우저의 로컬 저장소에만 저장됩니다. 다른 기기나 다른 브라우저와 자동 동기화되지 않습니다.
- 업무일지를 다른 사람에게 보내려면 공유 메뉴를 사용하거나 텍스트를 복사해 메신저/메일에 붙여 넣으세요. 로컬 데이터 자체는 공유되지 않습니다.
- PDF를 만들려면 결과 화면에서 **PDF 다운로드**를 누르거나 **저장 후 PDF 다운로드**를 누르세요. PDF는 기본 다운로드 폴더로 내려받으며, 브라우저의 다운로드 위치 설정에 따라 저장 위치를 물어볼 수 있습니다.
- PDF는 한국어/중국어가 보이도록 페이지를 이미지로 렌더링해 만듭니다. 따라서 PDF 안의 글자는 선택하거나 검색할 수 없습니다.
- 메모 분류와 문장 다듬기는 입력 문장을 기준으로 처리되므로 저장 전에 결과를 확인하세요.
