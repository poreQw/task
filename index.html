업무일지 사용 가이드

1. 날짜와 업무 내용을 입력하면 브라우저에 자동 저장됩니다. 항목을 여러 줄로 나누면 내일 할 일을 체크리스트로 사용할 수 있어요.

2. 지난 기록은 검색, 날짜 필터 또는 달력에서 찾아 열 수 있습니다. 템플릿을 저장해 반복 업무를 빠르게 작성하세요.

3. 전체 백업은 기록과 템플릿을 JSON 파일로 내려받습니다. 다른 브라우저에서 복원하려면 해당 파일을 선택하세요.

4. 데이터는 이 브라우저에만 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우기 전에 백업 파일을 보관하세요.
